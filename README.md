# Laptop-Sales-Analysis
Analyzed laptop sales data using Excel, Power Query, SQL, and Power BI. Performed data cleaning and transformation, developed an interactive dashboard, and tracked key KPIs such as Total Sales, Total Orders, Units Sold, Average Order Value (AOV), and Discount Rate to identify sales trends and support data-driven business decisions.
